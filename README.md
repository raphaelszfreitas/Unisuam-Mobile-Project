# ♟️ Jogo de Damas Mobile

## 📖 Sobre o Projeto

O **Jogo de Damas Mobile** é um projeto acadêmico desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas**, com o objetivo de aplicar conceitos de desenvolvimento mobile utilizando **React Native**.

A aplicação consiste em uma versão digital do tradicional jogo de damas, implementando toda a lógica das partidas diretamente na aplicação, sem a utilização de APIs ou serviços externos. Todas as regras do jogo, movimentações, validações e controle das partidas foram desenvolvidas por meio de funções em JavaScript.

Para facilitar os testes durante o desenvolvimento, foi utilizada a plataforma **Expo**, permitindo executar e validar a aplicação diretamente em dispositivos móveis.

---

# 🎯 Objetivos

* Desenvolver uma aplicação mobile utilizando React Native.

* Aplicar conceitos de programação orientada à lógica de negócios.

# ⚙️ Desafios do Desenvolvimento

O maior desafio deste projeto foi implementar toda a lógica do jogo sem depender de APIs ou motores prontos.

Foi necessário desenvolver manualmente funcionalidades como:

* Controle dos turnos dos jogadores;
* Validação de movimentos permitidos;
* Captura de peças adversárias;
* Promoção para dama;
* Atualização dinâmica do tabuleiro;
* Controle do estado da partida.

Esse processo exigiu atenção às regras oficiais do jogo e um forte foco em lógica de programação para garantir o funcionamento correto de cada jogada.

# ▶️ Como Executar

1. Clone este repositório.

```bash
git clone <URL_DO_REPOSITORIO>
```

2. Instale as dependências.

```bash
npm install
```

3. Inicie o projeto.

```bash
npx expo start
```

4. Escaneie o QR Code utilizando o aplicativo **Expo Go** ou execute em um emulador Android/iOS.
